# 2026-11-13 工作日志

## RTK 定位源选择 + 返回不断连

需求：RTK 设置页需要两个定位源选项（手机定位/RTK定位），RTK 连接后定位信息持续显示，返回不断连，再次进入仍能看到定位信息；选手机定位就一直走高德。

改动：
- `bridge/location.uts`：定位源判断从 `rtkIsActive()` 改为 `shouldUseRtk()`（= `LocationMode=="rtk" && rtkIsActive()`）。新增 `MODE_RTK`/`MODE_AMAP`、`currentMode()`（默认 rtk）、`shouldUseRtk()`。`setMode`/`getMode` 归一化，`getMode` 默认返回 "rtk"（旧值 "GPS"）。
- `pages/rtk-setting/rtk-setting.uvue`：
  - 顶部新增「定位源」tabs（手机定位 amap / RTK 定位 rtk），存 `LocationMode` storage。
  - amap 模式只显示说明；rtk 模式显示原连接界面。
  - `onUnload` 不再断开 RTK socket（连接是 tdyb-rtk 模块级全局的），只 `unregisterDataListener` + `stopBluetoothDiscovery`。
  - `onMounted`/`onShow` 用 `syncConnectedState()`（`isBluetoothConnected`/`isTcpConnected` + `getLastFix()`）恢复连接状态与定位数据，并 `registerDataListener` 继续更新。

关键机制：RTK socket 连接与 `lastFix` 缓存都在 `uni_modules/tdyb-rtk/utssdk/app-android/index.uts` 模块级静态变量里，跨页面存活；页面只是它的视图，销毁后重新注册监听即可恢复。
